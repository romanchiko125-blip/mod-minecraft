# City Villages (Minecraft/Forge 26.1.2)

Ты прав: в этом проекте целевая версия — **Minecraft 26.1.2**.

## Быстрая инструкция
1. Установи JDK 21.
2. Открой проект в IntelliJ IDEA (через `build.gradle`).
3. Дождись синхронизации Gradle.
4. Запусти задачу `build` в Gradle Tool Window.
5. Возьми `jar` из `build/libs/` и закинь в папку `mods`.

## Подробно
- В `build.gradle` выставлена зависимость `net.minecraftforge:forge:26.1.2`.
- Проект рассчитан на Java 21.
- Мод-файл после сборки: `build/libs/cityvillages-1.0.0.jar`.

## Установка в игру
1. Запусти Minecraft/Forge 26.1.2 один раз.
2. Открой папку игры и папку `mods`.
3. Скопируй `cityvillages-1.0.0.jar` в `mods`.
4. Запусти игру и проверь, что мод отображается в списке модов.
