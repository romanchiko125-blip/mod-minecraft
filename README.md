# City Villages (Forge 26.1.2)

Мод для **Minecraft 1.13.2 + Forge 26.1.2**.

Что делает мод:
- Больше обычных животных (овцы, свиньи, коровы, куры, волки, рыба).
- Больше жителей/котов/железных големов в мире (через таблицы спавна).
- Больше лута с мобов.

---

## 1) Что установить заранее

1. **Java 8 (JDK 1.8)**.
2. **IntelliJ IDEA** (Community или Ultimate).
3. **Forge 26.1.2** для клиента Minecraft 1.13.2 (чтобы потом запустить игру с модом).

> Важно: эта сборка мода заточена именно под Forge `1.13.2-26.1.2`.

---

## 2) Как открыть проект в IntelliJ IDEA

1. Открой IntelliJ IDEA.
2. Нажми **Open** и выбери папку проекта `mod-minecraft`.
3. IDEA увидит `build.gradle` и предложит импорт Gradle-проекта — соглашайся.
4. Дождись, пока Gradle скачает зависимости (может занять несколько минут).

Если IDEA попросит JDK:
- укажи **JDK 1.8**.

---

## 3) Как собрать `.jar`

### Вариант A: через окно Gradle в IDEA
1. Открой справа вкладку **Gradle**.
2. Перейди в: `cityvillages -> Tasks -> build -> build`.
3. Двойной клик по задаче **build**.
4. После успешной сборки файл мода появится в папке:
   - `build/libs/cityvillages-1.0.0.jar`

### Вариант B: через встроенный терминал IDEA
1. Открой **Terminal** в IDEA.
2. Выполни:
   - Linux/macOS: `./gradlew build`
   - Windows: `gradlew.bat build`
3. Готовый `.jar` будет в `build/libs/`.

---

## 4) Как установить мод в игру

1. Установи и запусти профиль **Forge 1.13.2-26.1.2** хотя бы один раз.
2. Открой папку `.minecraft/mods`.
3. Скопируй `cityvillages-1.0.0.jar` в папку `mods`.
4. Запусти Minecraft через Forge-профиль.
5. В главном меню зайди в список модов и проверь, что `City Villages` загружен.

---

## 5) Как проверить, что всё работает

1. Создай новый мир (лучше Creative для теста).
2. Найди деревню.
3. По миру будет больше обычных животных и рыбы.
4. При убийстве мобов должен выпадать увеличенный лут.

---

## 6) Частые проблемы

### Проблема: мод не грузится
- Проверь версию Forge: должна быть **ровно 26.1.2**.
- Проверь версию Minecraft: должна быть **1.13.2**.
- Проверь Java: нужна **Java 8**.

### Проблема: нет файла `.jar`
- Убедись, что сборка завершилась без ошибок.
- Проверь папку `build/libs/`.

### Проблема: IDEA не видит Gradle
- Закрой проект и открой снова через `build.gradle`.
- В настройках Gradle выбери JDK 1.8.
